# Kafka Recovery and Docker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace local wakeups with Kafka while preserving DB checkpoints, enforce account-level leases, and recover active jobs after backend or broker restarts in Docker Compose.

**Architecture:** A transactional outbox publishes keyed wakeups; Kafka is a wakeup transport rather than the source of job state. Consumers acquire a PostgreSQL lease before running one action and acknowledge only after the action transaction completes. Recovery scans DB state so a lost Kafka topic cannot strand a job. Delivery is at-least-once: a crash after the HOF response but before checkpoint commit may repeat the final action, which is explicitly accepted.

**Tech Stack:** Spring Kafka, PostgreSQL 18, Apache Kafka KRaft, Docker Compose, Spring Boot Actuator, Testcontainers

**Repository note:** `hof_backend` is not currently inside a Git repository. Do not initialize or relocate it automatically; preserve each task boundary with the listed tests unless the user separately authorizes repository setup.

        kafkaTemplate.send(row.topic, row.eventKey, row.payload).get(10, TimeUnit.SECONDS)

- [ ] **Step 4: Consume idempotently and acknowledge after DB completion**

```kotlin
@KafkaListener(topics = ["hof.automation.wakeup"], groupId = "hof-automation", containerFactory = "automationKafkaListenerFactory")
fun consume(payload: String, acknowledgment: Acknowledgment) {
    val event = objectMapper.readValue(payload, AutomationWakeupEvent::class.java)
    if (consumedEventRepository.existsById(event.eventId)) { acknowledgment.acknowledge(); return }
    if (!leaseService.tryAcquire(event.accountId, workerId, timeProvider.now(), Duration.ofSeconds(30))) return
    try {
        runner.runOne(event.accountId)
        consumedEventService.record(event.eventId)
        acknowledgment.acknowledge()
    } finally {
        leaseService.release(event.accountId, workerId)
    }
}
```
