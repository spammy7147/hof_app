# 전투 맵 자동화 카테고리 목록 설계

## 목적

전투 맵 자동화 편집기의 평면 맵 목록을 전투 탭과 같은 `카테고리 → 그룹 → 맵` 계층으로 바꾼다. 맵이 많아도 원본 HOF의 분류를 따라 탐색할 수 있어야 하며, 선택 상태는 별도 체크박스 대신 개별 맵 카드 전체로 표현한다.

## 범위

이번 변경은 `전투 맵 자동화` 편집기의 `맵 찾기` 영역에만 적용한다.

- 기존 `선택한 맵 · 실행 순서` 영역을 유지한다.
- 기존 일일 목표, 오늘 성공 횟수, 1회/3회 전투 안내, 프리셋 선택, 실행 순서, 저장 및 삭제 동작을 유지한다.
- 서버 API와 저장 요청 형식은 변경하지 않는다.
- 전투 탭의 실제 전투 실행 화면은 변경하지 않는다.
- 모험 맵 자동화와 퀘스트 자동화 편집기는 변경하지 않는다.

## 선택한 접근

전투 탭이 사용하는 계층을 전투 맵 자동화의 카탈로그에도 적용한다.

1. 자동화에서 지원하는 카테고리를 전투 탭 순서로 표시한다.
2. 한 번에 하나의 카테고리를 펼친다.
3. 펼친 카테고리 안에서 여러 그룹을 동시에 펼칠 수 있다.
4. 그룹 안의 개별 맵 카드를 눌러 자동화에 추가하거나 제거한다.

상단 카테고리 필터 칩으로 목록을 바꾸는 방식은 화면이 짧아지는 장점이 있지만 전투 탭과 조작 방식이 달라지므로 채택하지 않는다.

## 화면 구조

### 선택한 맵 영역

현재 편집기의 첫 영역을 그대로 유지한다.

- 선택한 맵은 실행 순서대로 표시한다.
- 각 설정 카드에서 일일 목표와 프리셋을 편집한다.
- 기존 위/아래 이동과 제거 동작을 유지한다.
- 저장되는 `executionOrder`는 이 영역의 순서를 따른다.

### 맵 찾기 영역

검색창 아래에 카테고리 트리를 표시한다.

#### 카테고리 행

- 카테고리명, 설명, 맵 개수, 펼침 화살표를 표시한다.
- 왼쪽 아이콘이나 선택 체크박스를 표시하지 않는다.
- 펼친 카테고리에도 선택된 것처럼 보이는 민트색 테두리나 배경을 사용하지 않는다.
- 펼침 상태는 화살표 방향과 하위 행 노출만으로 표현한다.
- 새 카테고리를 펼치면 이전 카테고리는 접힌다.

#### 그룹 행

- 그룹명, 권장 레벨, 포함 맵 개수, 펼침 화살표를 표시한다.
- 아이콘과 선택 강조를 사용하지 않는다.
- 같은 카테고리 안에서 여러 그룹을 동시에 펼칠 수 있다.
- 원본 HOF의 `groupOrder` 순서를 유지한다.

#### 맵 행

- 그룹 접두어를 제거한 짧은 맵 이름을 제목으로 표시한다.
- 키, 도전/승리 가능 횟수, 쿨다운, 소비 Time 중 값이 있는 정보만 보조 문구로 표시한다.
- 별도 체크박스나 왼쪽 선택 칸을 표시하지 않는다.
- 카드 전체를 누르면 선택 또는 선택 해제한다.
- 선택된 맵만 민트색 테두리와 은은한 배경을 사용하고 오른쪽에 작은 `선택됨` 문구를 표시한다.
- 선택되지 않은 맵은 중립색 카드로 표시한다.
- 확인되지 않았거나 자동화에서 지원하지 않는 맵은 새 선택 후보에서 제외한다.

## 검색 동작

검색은 현재와 같이 맵 이름, 그룹명, 권장 레벨을 대상으로 하며 앞뒤 공백과 대소문자를 무시한다.

- 검색어가 비어 있으면 사용자가 선택한 카테고리와 그룹의 접힘 상태를 사용한다.
- 검색어가 있으면 일치하는 맵만 표시한다.
- 검색 결과가 있는 카테고리와 그룹은 자동으로 펼친 상태로 표시한다.
- 검색어를 지우면 검색 전 사용자가 지정했던 접힘 상태로 돌아간다.
- 결과가 없고 모든 카테고리 요청이 끝났으면 `검색 가능한 맵이 없습니다.`를 표시한다.

## 데이터와 상태

### 카탈로그 데이터

- 기존 `filterBattleAutomationCategories`로 모험맵과 유니온을 새 선택 후보에서 제외한다.
- 기존처럼 지원 카테고리의 맵을 불러와 저장된 설정을 최신 카탈로그 정보로 보강한다.
- 카테고리는 `orderBattleCategories`로 전투 탭과 같은 순서로 정렬한다.
- 카테고리 내부 맵은 `groupBattleMaps`로 그룹화한다.
- 맵 제목과 보조 정보는 `formatAutomationMapListName`, `formatAutomationMapListMeta`를 사용한다.
- 이미 선택한 맵과 카탈로그 맵의 대응에는 `battleMapIdentity(categoryId, mapCode)`를 사용한다.

### 화면 상태

맵 트리는 다음 로컬 상태를 가진다.

- `expandedCategoryId`: 현재 펼친 카테고리 하나 또는 `null`
- `expandedGroupKeys`: 사용자가 펼친 그룹 키 목록
- `query`: 검색어

검색에 의한 자동 펼침은 파생 상태로 계산하고 사용자 접힘 상태를 덮어쓰지 않는다.

### 선택 처리

- 선택하지 않은 맵을 누르면 기존 `selectBattleMap(..., true)`를 사용해 draft 끝에 추가한다.
- 선택한 맵을 누르면 기존 `selectBattleMap(..., false)`를 사용해 draft에서 제거하고 실행 순서를 연속 값으로 정규화한다.
- 표시용 카테고리/그룹 정렬은 draft의 실행 순서를 변경하지 않는다.
- 서버 저장 요청은 기존 `buildBattleMapAutomationRequest`를 그대로 사용한다.

## 컴포넌트 경계

`BattleMapAutomationEditor`가 데이터 로딩, draft, 검색어, 접힘 상태, 저장과 프리셋 모달을 계속 소유한다. 선택한 맵 설정과 카탈로그가 하나의 긴 화면이므로 중첩 FlatList를 만들지 않고 기존 단일 FlatList를 유지한다.

### 카탈로그 행 모델

순수 도메인 헬퍼가 정렬된 카테고리와 카탈로그, 검색어, 접힘 상태를 받아 다음 표시 행을 만든다.

- 카테고리 행
- 카테고리 로딩/오류/빈 상태 행
- 그룹 행
- 개별 맵 행

헬퍼는 입력 배열을 변경하지 않으며 draft나 저장 상태를 알지 않는다. 검색 중 자동 펼침도 이 행 모델 계산에서만 적용해 사용자의 접힘 상태를 덮어쓰지 않는다.

### 표시 컴포넌트

카테고리, 상태, 그룹, 맵 행은 작고 독립적인 표시 컴포넌트로 분리한다. 각 컴포넌트는 표시 데이터와 callback만 받고 draft를 직접 변경하지 않는다. 맵 행은 `onToggleMap(map, selected)`을 편집기에 전달하며, 편집기가 기존 `selectBattleMap`으로 draft를 갱신한다.

편집기의 저장, 프리셋, 진행률 상태는 카탈로그 행 모델과 표시 컴포넌트에 넣지 않는다.

## 로딩 및 오류 처리

- 카테고리 목록 로딩/오류 안내는 기존 편집기 상단에 유지한다.
- 카테고리 맵 로딩 중에는 해당 카테고리 하위에 로딩 행을 표시한다.
- 특정 카테고리 맵 로딩 실패는 해당 카테고리 하위에 오류와 `다시 시도`를 표시한다.
- 다른 카테고리의 성공 결과는 실패한 카테고리 때문에 숨기지 않는다.
- 저장 중이거나 초기 draft가 준비되지 않았으면 카테고리/그룹 펼침은 허용하되 맵 선택 변경은 막는다.
- 카테고리 재시도와 늦게 도착한 요청의 세대 차단은 기존 편집기 로딩 로직을 유지한다.

## 접근성

- 카테고리와 그룹 행은 `button` 역할과 `expanded` 상태를 제공한다.
- 맵 카드는 시각적 체크박스 없이 `checkbox` 역할과 `checked` 상태를 제공한다.
- 맵 카드 전체의 터치 높이는 최소 44dp를 유지한다.
- 선택 여부는 색상에만 의존하지 않고 `선택됨` 문구와 접근성 상태로 함께 표현한다.
- 비활성화 중인 맵 카드는 `disabled` 상태를 제공하고 callback에서도 변경을 방어한다.

## 테스트

### 도메인 테스트

- 지원 카테고리가 전투 탭 순서로 표시되는지 검증한다.
- 카탈로그가 HOF 그룹 순서와 맵 순서를 유지하는지 검증한다.
- 짧은 자동화용 맵 이름과 보조 정보가 사용되는지 검증한다.
- 검색 결과가 카테고리/그룹 단위로 올바르게 제한되는지 검증한다.
- 표시용 그룹화가 입력 배열과 draft 실행 순서를 변경하지 않는지 검증한다.

### 컴포넌트 테스트

- 카테고리 한 개만 펼쳐지고 그룹 여러 개가 펼쳐지는지 검증한다.
- 카테고리와 그룹에 아이콘·선택 강조·체크박스가 없는지 검증한다.
- 선택된 맵만 카드 전체 강조와 `선택됨` 문구를 표시하는지 검증한다.
- 맵 카드 선택/해제가 기존 draft와 저장 요청을 정확히 갱신하는지 검증한다.
- 검색 시 일치하는 카테고리와 그룹이 자동으로 펼쳐지고 검색 해제 시 이전 접힘 상태로 복원되는지 검증한다.
- 카테고리별 로딩, 오류, 재시도, 빈 상태를 검증한다.
- 저장 중 맵 변경이 차단되는지 검증한다.
- 카테고리 표시 순서가 선택한 맵 실행 순서와 저장 순서를 변경하지 않는지 검증한다.

### 회귀 검증

- 전투 맵 자동화 편집기 전체 컴포넌트 테스트
- 전투 맵 및 전투 맵 자동화 도메인 테스트
- 전체 앱 테스트
- TypeScript 타입 검사

## 완료 기준

- 맵 찾기 영역이 전투 탭과 같은 카테고리/그룹/맵 계층으로 보인다.
- 카테고리와 그룹에는 선택된 것처럼 보이는 강조나 왼쪽 아이콘이 없다.
- 개별 맵은 체크박스 없이 카드 전체 선택 상태를 명확히 보여준다.
- 검색, 선택/해제, 저장, 카테고리별 오류 복구가 기존 기능을 깨뜨리지 않는다.
- 저장 API와 자동화 실행 순서 의미가 변경되지 않는다.
