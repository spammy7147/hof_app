# 모험맵 자동화 그룹 카탈로그 설계

## 목적

`모험맵 자동화` 편집기의 평면 카탈로그를 `그룹 → 맵` 계층으로 바꾼다. 모험맵이 많아도 원본 HOF의 그룹 순서대로 탐색할 수 있어야 하며, 전투맵 자동화에서 확정한 접기·펼치기와 카드 전체 선택 방식을 따른다.

## 범위

이번 변경은 `모험맵 자동화` 편집기의 `모험맵 찾기` 영역에만 적용한다.

- 기존 `선택한 모험맵 · 실행 순서` 영역을 유지한다.
- 기존 초기화 상태, 맵 실행 가능 상태, 쿨다운, 열쇠, 횟수, 프리셋, 저장 및 삭제 동작을 유지한다.
- 서버 API와 저장 요청 형식은 변경하지 않는다.
- 자동화 실행 로직과 한국 시간 00시 초기화 로직은 변경하지 않는다.
- 전투맵 자동화와 퀘스트 자동화 편집기는 변경하지 않는다.

## 검토한 접근

### A. 간결한 그룹 행 — 채택

그룹 행에는 그룹명, 맵 개수, 권장 레벨만 표시한다. 실행 가능 여부, 쿨다운, 열쇠와 횟수는 펼친 그룹의 개별 맵 카드에서 확인한다.

- 전투맵 그룹 행과 조작 방식이 일관된다.
- 상태가 자주 바뀌어도 그룹 행 높이와 정보 구조가 안정적이다.
- 한 화면에서 더 많은 그룹을 확인할 수 있다.

### B. 그룹 상태 요약 — 미채택

접힌 그룹에도 실행 가능 맵 수와 대기 맵 수를 표시하는 방식이다. 그룹을 열지 않고 상태를 파악할 수 있지만, 상태 중복으로 행이 커지고 자주 변하는 요약이 시선을 분산하므로 채택하지 않는다.

## 화면 구조

### 선택한 모험맵 영역

기존 편집기의 첫 영역을 그대로 유지한다.

- 선택한 맵은 실제 실행 순서대로 표시한다.
- 각 설정 카드에서 상태와 제한 정보를 확인하고 프리셋을 편집한다.
- 기존 위·아래 이동과 제거 동작을 유지한다.
- 저장되는 `executionOrder`는 이 영역의 순서만 따른다.

### 모험맵 찾기 영역

모험맵은 하나의 `adventure_map` 카테고리만 사용하므로 카테고리 행을 추가하지 않는다. 검색창 아래에 그룹 행을 바로 표시한다.

#### 그룹 행

- 그룹명, 포함 맵 개수, 권장 레벨, 펼침 화살표를 표시한다.
- 그룹명이 비어 있으면 `기타`로 표시한다.
- 별도 아이콘, 체크박스, 선택된 것처럼 보이는 민트색 강조를 사용하지 않는다.
- 편집기를 처음 열면 모든 그룹은 접힌 상태로 시작한다.
- 같은 카테고리 안에서 여러 그룹을 동시에 펼칠 수 있다.
- 원본 HOF의 `groupOrder` 순서를 유지한다.

#### 맵 행

- 현재 모험맵 카드의 제목과 실행 상태를 유지한다.
- 그룹명은 상위 그룹 행에서 이미 보이므로 맵 카드의 보조 문구에서는 중복 표시하지 않는다.
- 권장 레벨과 관측 상태 상세를 보조 문구로 표시한다.
- 쿨다운, 열쇠, 가능 횟수, 도전 잔여, 승리 잔여 중 값이 있는 제한 정보를 기존 칩으로 표시한다.
- 별도 시각적 체크박스를 추가하지 않는다.
- 카드 전체를 누르면 선택 또는 선택 해제한다.
- 선택된 맵은 민트색 테두리와 은은한 배경, `선택됨` 문구로 상태를 표시한다.
- 선택하지 않은 맵은 현재 중립색 카드와 실행 상태 문구를 유지한다.

## 검색 동작

검색 대상은 현재와 같이 맵 이름, 그룹명, 권장 레벨이다.

- 검색어가 비어 있으면 사용자가 직접 지정한 그룹 접힘 상태를 사용한다.
- 검색어가 있으면 일치하는 맵만 표시한다.
- 일치하는 맵이 포함된 그룹은 자동으로 펼친 상태로 표시한다.
- 검색 결과의 자동 펼침 그룹 행은 사용자가 직접 접을 수 없게 한다.
- 검색 자동 펼침은 파생 상태로만 계산하며 수동 `expandedGroupKeys`를 변경하지 않는다.
- 검색어를 지우면 검색 전 사용자가 펼쳤던 여러 그룹 상태로 돌아간다.
- 로딩이 끝난 뒤 일치하는 맵이 없으면 `검색 가능한 모험맵이 없습니다.`를 표시한다.

## 데이터와 상태

### 그룹 데이터

모험맵 전용 순수 헬퍼가 필터된 카탈로그를 `groupName`, `groupOrder`, `mapOrder` 기준으로 그룹화하고 화면 행을 만든다.

- 그룹 키는 `categoryId`, `groupOrder`, 정규화된 그룹명을 길이 구분 형식으로 조합해 충돌을 방지한다.
- 그룹명이 비어 있으면 `기타`를 사용한다.
- 각 그룹은 첫 번째로 확인되는 권장 레벨과 포함 맵 수를 제공한다.
- 그룹과 맵은 원본 순서를 유지한다.
- 헬퍼는 입력 배열과 선택 draft를 변경하지 않는다.

전투맵의 `groupBattleMaps`는 모험맵 허수아비 일부를 표시 대상에서 제외하므로 그대로 재사용하지 않는다. 현재 `filterAdventureMapCatalog`에 표시되는 모든 resolved 모험맵을 유지하는 전용 그룹화 경계를 사용한다.

### 편집기 상태

`AdventureMapAutomationEditor`가 다음 상태를 계속 소유한다.

- 기존 draft, 카탈로그, 프리셋, 로딩·오류·저장 상태
- `query`: 검색어
- `expandedGroupKeys`: 사용자가 직접 펼친 그룹 키 목록

검색 중 자동 펼침은 행 모델을 만들 때만 적용한다. 표시용 그룹 정렬은 선택한 맵의 실행 순서와 서버 요청 순서를 변경하지 않는다.

## 컴포넌트 경계

선택 설정과 카탈로그가 하나의 긴 화면이므로 기존 단일 `FlatList`를 유지하고 중첩 목록을 만들지 않는다.

### 카탈로그 행 모델

순수 도메인 헬퍼가 정렬된 모험맵 카탈로그, 검색어, 수동 펼침 상태를 받아 다음 행을 반환한다.

- 그룹 행
- 개별 맵 행

로딩과 오류는 현재 편집기의 상단 리소스 상태로 유지한다. 빈 검색 결과 행은 모든 맵 요청이 완료된 상태에서 편집기가 추가한다.

### 표시 컴포넌트

- 그룹 행은 표시 데이터, 펼침 상태, 검색 중 상호작용 차단 여부와 callback만 받는다.
- 맵 행은 기존 상태·제한 정보와 선택 상태, callback만 받는다.
- 표시 컴포넌트는 draft, 프리셋, 저장 상태를 직접 변경하지 않는다.

전투맵 행 컴포넌트를 억지로 공용화하지 않는다. 모험맵 카드는 실행 상태와 제한 칩이 필요하므로 모험맵 전용 그룹·맵 행으로 분리하고, 색상·간격·접근성 계약만 일관되게 맞춘다.

## 선택과 저장 처리

- 선택하지 않은 맵을 누르면 기존 `selectAdventureMap(..., true)`로 draft 끝에 추가한다.
- 선택한 맵을 누르면 기존 `selectAdventureMap(..., false)`로 draft에서 제거하고 실행 순서를 정규화한다.
- 저장 중 또는 초기 카탈로그 로딩 중에는 새 맵 선택과 선택 해제를 막는다.
- 렌더 시점에 만들어진 오래된 맵 callback도 실행 시점과 draft updater 안에서 현재 busy 상태를 다시 확인한다.
- 서버 저장 성공 기준점은 실제 제출한 draft 스냅샷을 사용한다.
- 서버 저장 요청은 기존 `buildAdventureMapAutomationRequest`를 유지한다.

## 로딩 및 오류 처리

- 카테고리 로딩·오류 안내와 `다시 시도`를 유지한다.
- 모험맵 로딩·오류 안내와 `다시 시도`를 유지한다.
- 프리셋 로딩·오류 안내를 유지한다.
- 카탈로그 갱신에서 사라진 선택 맵은 상단 설정에 `현재 상태 확인 불가`로 유지하며, 새 선택 카탈로그에서만 제외한다.
- 늦게 도착한 카탈로그와 프리셋 요청은 기존 generation 검사를 유지한다.
- 로딩이나 검색 결과가 없다는 이유로 저장된 선택 설정을 제거하지 않는다.

## 접근성

- 그룹 행은 `button` 역할과 `expanded` 상태를 제공한다.
- 검색 중 자동 펼침 그룹은 `disabled` 상태와 검색 결과용 레이블을 제공한다.
- 맵 카드는 시각적 체크박스 없이 `checkbox` 역할과 `checked` 상태를 제공한다.
- 그룹과 맵 행은 최소 44dp 터치 영역을 유지한다.
- 맵 선택 여부는 색상만이 아니라 `선택됨` 문구와 접근성 상태로 함께 표현한다.
- 저장 중 맵 카드는 `disabled` 상태를 제공하고 callback에서도 변경을 방어한다.

## 테스트

### 도메인 테스트

- 그룹이 `groupOrder` 순서로, 맵이 `mapOrder` 순서로 표시되는지 검증한다.
- 그룹명이 비어 있는 맵이 `기타`로 묶이는지 검증한다.
- 같은 이름과 순서를 가진 충돌 가능한 그룹 키가 안전한지 검증한다.
- 현재 표시되는 허수아비를 포함해 resolved 모험맵이 누락되지 않는지 검증한다.
- 검색 결과가 일치하는 그룹과 맵으로 제한되는지 검증한다.
- 표시용 그룹화가 입력 배열과 draft 실행 순서를 변경하지 않는지 검증한다.

### 컴포넌트 테스트

- 여러 그룹을 동시에 펼칠 수 있는지 검증한다.
- 그룹 행에 아이콘·체크박스·선택 강조가 없는지 검증한다.
- 선택된 맵만 카드 전체 강조와 `선택됨` 문구를 표시하는지 검증한다.
- 맵 선택·해제가 기존 draft와 저장 요청을 정확히 갱신하는지 검증한다.
- 검색 시 일치 그룹이 자동으로 펼쳐지고 검색 해제 시 이전 여러 그룹 상태로 복원되는지 검증한다.
- 검색 시작 전에 보관한 그룹 callback이 검색 중 수동 펼침 상태를 바꾸지 못하는지 검증한다.
- 검색 결과 없음, 로딩, 오류와 재시도를 검증한다.
- 저장 중 현재 callback과 보관된 callback 모두 맵 설정을 변경하지 못하는지 검증한다.
- 그룹 표시 순서가 선택한 맵 실행 순서와 저장 순서를 변경하지 않는지 검증한다.

### 회귀 검증

- 모험맵 자동화 편집기 컴포넌트 테스트
- 모험맵 자동화 도메인 테스트
- 전체 앱 테스트
- TypeScript 타입 검사
- Android 개발 빌드에서 여러 그룹 펼침, 검색·해제 복원, 카드 선택·해제와 저장·재진입을 확인한다.

## 완료 기준

- `모험맵 찾기`가 간결한 `그룹 → 맵` 계층으로 보인다.
- 여러 그룹을 동시에 펼칠 수 있다.
- 현재 보이는 모험맵이 그룹화 과정에서 누락되지 않는다.
- 개별 맵은 별도 시각적 체크박스 없이 카드 전체 선택 상태를 명확히 보여준다.
- 검색 해제 후 수동 그룹 펼침 상태가 복원된다.
- 그룹 표시 순서가 선택 맵의 실행 순서나 저장 요청 순서를 바꾸지 않는다.
- 기존 초기화, 상태·제한 표시, 프리셋, 저장·삭제 동작이 유지된다.
